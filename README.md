# Veritabani Normalizasyon Kurallari (1NF, 2NF, 3NF)

Bu depo, iliskisel veritabani yonetim sistemlerinde (RDBMS) veri tekrarini (redundancy) onlemek, veri tutarliligini artirmak ve guncelleme anomalilerini engellemek icin uygulanan normalizasyon adimlarini ve ornek Ogrenci Bilgi Sistemi (OBS) veri modellemesini icerir.

## Icerik

* **Normal Formlar (1NF, 2NF, 3NF):** Birinci, ikinci ve ucuncu normal form kurallarinin teorik aciklamalari.
* **OBS (Ogrenci Bilgi Sistemi) Uygulamasi:** Tablolarin fonksiyonel bagimliliklarina gore ayristirilmasi ve iliskisel sema tasarimi.
